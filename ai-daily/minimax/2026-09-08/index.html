🎓 学术葡萄牙尚帕利莫基金会领衔的国际团队 9-8 在 Cell 发表两项研究,近 20 年努力的成果:① 第一项研究完整绘制果蝇中枢神经系统 16.67 万神经元的连接图谱,识别出超 1.1 万种不同的细胞类型;参与机构包括美国霍华德·休斯医学研究所(HHMI)、英国剑桥大学、MRC 分子生物学实验室、Google 研究院;与以往只关注大脑的图谱不同,新连接组保留了大脑与神经索之间的联系,使得跨越这一分界线的神经路径成为可能——AI 在追踪神经元连接时发挥了关键作用,并能预测神经元之间是激发还是抑制,为理解信号内容提供了线索;② 第二项研究追踪味觉信号从全身感官神经元到运动神经元的完整路径,揭示味觉如何驱动进食、回避和激素释放等行为;团队逐一识别并分类所有味觉受体神经元(分布在腿部、翅膀、口器和喉咙内侧),并追踪其信号如何连接到控制摄食、运动、激素释放和求偶的回路——发现虽然味觉传感器遍布全身,但携带相似"价值"信号的神经元通常会汇聚到大脑深层的同一回路中,同时保留位置信息,以便动物根据味道来源做出不同反应;③ 关键设计:许多回路并不是直接激活运动神经元,而是先对进食动作保持抑制,直到诱人味道足够强烈时才解除抑制,这种设计有助于防止误食有害物质;④ 全新发现:首次展示了味觉与激素反应之间的精确神经连接,动物在营养完全吸收之前神经系统已经告诉身体食物即将到来,或有助于解释为什么零卡路里甜味剂也能促使胰岛素释放。

🎓 学术DeepSeek Harness 8 月中旬开源后 3 周 GitHub 达 20 万星:① GitHub 排名参照:在 GitHub 上要堆到 20 万星,大多数项目得熬很久,例如曾经火得一塌糊涂的 OpenClaw 小龙虾用了 3 个月——但 DeepSeek Harness 不到 3 周就把注意力拽过去;② 技术定位:Harness 不是模型也不是某个单点工具,而是一套把大模型接工具、接流程、把任务干到底的框架——模型负责"想",Harness 负责"执行":读文件、跑代码、存进度,你想让它怎么干,框架就把手脚给你搭起来;③ 核心哲学:"Everything is a plugin"——把每一个组件(从模型适配器到智能体循环)都当作可互换的插件,挑战传统单体架构(修改一个组件经常需要复杂的整体调整);④ 底层技术:基于 Cordis 元框架(强调时空可组合性),这种"可组合"特性对开发者是梦寐以求的——可以动态添加和移除组件而不破坏系统和谐;⑤ 4 种预设模式:Standard(全功能)、Minimal(极简)、Code(代码交互模式)、Log(只读);⑥ 模型无关:不绑定任何特定 AI 模型,支持 Anthropic / OpenAI / Google Gemini 等多种提供商,可让开发者在不被锁死的前提下尝试不同模型;⑦ Subagent 委托:支持 Claude Code 和 OpenAI Codex 的子代理,可以根据任务复杂度动态委托。
