Claude Science 多 Agent 端到端生成首张完整紫外全天图,1/3 天区由模型推算
重磅·产学研
🌍 全球信号 前沿产业 学术成果 科学 Agent 紫外天文 Anthropic

🎓 学术Anthropic 10/8 公布 Johns Hopkins 天体物理学家 Brice Ménard 团队用 Claude Science 多 Agent 调度结果:Agent 自动下载 GALEX 远紫外 (FUV) 与近紫外 (NUV) 巡天数据,校准后用 inpainting 补出 1/3 未被紫外望远镜直接观测的天区,逐像素标注"测得"或"预测";基于 Gaia 数据估算上亿颗恒星的紫外贡献作为先验,在被遮住的已观测区验证集上,预测与实测偏差约 10%。

🏢 产业该案例把"科学 Agent"从论文写作辅助推进到跨数据源、跨步骤的端到端研究流水线,意味着天文、气候、材料等数据密集学科可以用 Claude/Codex/Gemini 跑出可发表级别的初步结果,缩短科学发现周期;但 Agent 在两轮审查中漏掉了 GALEX 圆形扫描留下的可见残痕,暴露视觉 Agent 在做物理结构判断时仍会忽略低层先验,需要人机协同兜底。

关键数据:GALEX FUV 覆盖 64% / NUV 覆盖 76% 天空;Claude 调度多个 Agent 下载并校准公开巡天;在可见光/红外/射电/紫外多波段统计关系下补全;预测与实测偏差约 10%;终版历经十多版迭代,逐像素标明来源。

🌍 全球信号 学术成果 产学研交叉 形式化验证 OpenAI

🎓 学术OpenAI 10/6 在 GitHub 公开 722 份模型生成数学手稿,涵盖组合数学/几何/数论/理论 CS/代数/拓扑/概率/统计物理/数学物理共 9 个领域,约 372 个结果族,约 4000 道题目尝试,平均每条结果用约 3 小时 ChatGPT Pro 推理;约 300 份 (42%) 完成 Lean 形式化,触及黎曼猜想推进、霍奇猜想一个特例情形、四维 Kakeya 猜想的解决;陶哲轩等转载 AHM 抵制声明,称这是"力量展示",非学术贡献。

🏢 产业对 OpenAI 而言,该发布把"模型=研究合作者"叙事推到极致,商业化上为 ChatGPT Pro 价值提供背书;但 OpenAI 未公开背后模型名称、所用提示词、完整问题集,8 日前已撤回 3 篇、修订 14 篇,部分手稿存在"形式化证明与正文论断不对应"问题,企业级用户由此看清当前 AI 数学仍需人机协同验证,不能直接当证明使用。

关键数据:722 份手稿 / 372 个结果族 / ~4000 题 / 约 42% 通过 Lean 形式化;触及黎曼猜想推进、霍奇猜想特例、四维 Kakeya 猜想;3 份被撤回、14 份修订;AGMAI 顾问小组称其工作不代表认可 OpenAI 做法。

Stowers 领衔 ARPA-H 2860 万美元 用 DAmFRET 测 5 万种蛋白质聚集训练 AI 预测神经退行病变
重要·产学研
🌍 全球信号 学术成果 前沿产业 AI4S 蛋白质 ARPA-H

🎓 学术Stowers Institute 联合 UC Berkeley 等启动 NATIVE-ID 项目 (属 ARPA-H BIOGAMI 计划),Halfmann 实验室承担关键角色获约 410 万美元,在酵母中用 DAmFRET (Distributed Amphifluoric FRET) 测 5 万种蛋白质的聚集倾向,跨 100 万样本产生 100 亿次聚集测量;研究目标是"读懂"无序蛋白 (IDP) 的构象语言,训练 AI 预测阿尔茨海默、帕金森、ALS、亨廷顿等神经退行病的发病概率和年龄。

🏢 产业AlphaFold 等 AI 已能稳定预测结构化蛋白,但 ~1/3 蛋白无稳定结构,IDP 是药物开发长期盲区;Halfmann 实验室产生的高质量细胞级数据可直接喂养到 AI 模型,使 DeepMind/Insilico/Recursion 等 AI 制药公司在不依赖 X 射线晶体学的前提下,具备用 AI 设计"治疗性 IDP"以拦截有害蛋白-蛋白相互作用的能力,把神经退行病药物发现从"试错"推进到"计算驱动"。

关键数据:5 万种蛋白质 / 100 万样本 / 100 亿次聚集测量;410 万美元 / 2 年;5 类神经退行病;NIH ARPA-H BIOGAMI 计划;NATIVE-ID 项目由 Stowers 与 UC Berkeley 创新基因组研究所联合牵头。

🎓 学术Microsoft Research、Harvard、Broad Institute 联合推出 Project Quine,把基因组、蛋白质、化学、细胞状态、影像统一到同一表征空间,构建跨模态生物世界模型,支持"看-推-做"闭环推理;在测试中,Quine 用 一个周末 识别出一个潜在抗癌候选化合物,跨过传统数月药物筛选 + 验证流程。
