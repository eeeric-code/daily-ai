OpenAI GPT-5.6 Sol 在 ARC-AGI-3 得分 +188% 提升,关键靠"推理保留 + 上下文压缩"两项
🎓 学术 / 基准突破7-31 OpenAI 公告:GPT-5.6 Sol 在 ARC-AGI-3(全球公认最严苛的交互式推理基准,2026 年 7 月发布)得分从 7.8% 飙到 38.3%,提升 188%;同时输出 Token 降至 1/6(原 17.5 万字符窗口被压缩)。两项关键修改:①推理保留(inference preservation)用 Responses API 让模型保留私有思考过程 ②上下文压缩替换滚动截断,让早期观察和动作不丢失。
