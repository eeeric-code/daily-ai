上海六院结构化多智能体 LLM 急性缺血性卒中治疗推荐 准确率 73.1%→88.6% 幻觉率 33.6%→20.6%
重磅·产学研
🇨🇳 中国动向 学术成果 前沿产业 医疗 AI 多智能体 决策支持

🎓 学术上海六院团队在 JMIR 2026-07-30 (DOI: 10.2196/96304, PMID: 42531250) 报告结构化多智能体 LLM 框架,纳入 1055 例 A 组、721 例 B 组、144 例 C 组文献挑战病例与 161 例 D 组前瞻收集病例;由摘要智能体 + 指南推理链智能体 + 约束智能体三 Agent 协作,产出可勾选的治疗推荐 (静脉溶栓/血管内取栓/标准内科) + TOAST 分型;在 12 名医生前瞻研究中,有 AI 辅助 vs 无 AI 辅助的准确率从 73.1% 升至 88.6% (OR 2.86, 95% CI 2.27-3.60, P<0.001),TOAST 分型准确率 OR 3.63。

🏢 产业对基层与非专科医生,准确率提升最大 (初级非专科从 0.600 升到 0.846),为卒中资源分布不均的县乡医院提供"AI 第二意见";但病例与医生均来自单一机构,真实临床工作流与患者结局 (再通率/致残率/死亡率) 尚未评估,需前瞻多中心验证;模型层多智能体框架在 A 组治疗推荐准确率从 0.546-0.737 提升到 0.687-0.851,B 组从 0.587-0.698 提升到 0.671-0.813,平均提升约 18.9%。

关键数据:1981 例验证 + 161 例前瞻;多智能体框架使医生准确率 73.1%→88.6% (OR 2.86);TOAST 分型 OR 3.63;幻觉率 33.6%→20.6%;遗漏率 38.5%→24.5%;临床安全评分 3.70→4.01 (5 分制);JMIR 2026-07-30 刊发,DOI 10.2196/96304。

重磅·政策
🌍 全球信号 学术成果 政策监管 合成生物学 AI4S 生物安全

🎓 学术美国研究者 (Stanford 系) 在 Science 发表论文,使用 AI 用天然噬菌体作为模板,化学合成并测试近 300 个基因组,最终得到 16 种可行的合成病毒;与天然对应物相比,这些 AI 设计的病毒对 E. coli 表现出增强的杀伤效果;这是 AI 设计功能性病毒基因组能力的关键里程碑,证明自然基因组可以被工程化并产生可行 (且功能增强) 的病毒后代。

🏢 产业该研究为合成生物学开启"AI 驱动的噬菌体疗法"新范式,有望解决抗生素耐药菌问题;但同时引发生物安全担忧,UNSW 的 Fatemeh Vafaee 教授强调"该研究方法本身令人担忧,不仅仅是病毒",Isaac Bogoch 等传染病专家呼吁"先有生物安全措施,再扩散技术";同周 Trump 行政令要求 AI 公司自愿评估、Postman/Super Micro 等企业被起诉/合规,AI for Science 进入"能力扩展 > 安全护栏"窗口期。

关键数据:~300 个合成基因组,16 种可行合成病毒,杀伤 E. coli 效果增强;Stanford 团队;Science 期刊;UNSW Fatemeh Vafaee 警告"方法比结果更值得警惕";同步美国签署行政令推动 AI 自愿评估,AI 滥用防保障措施升级。

字节 Seed 团队发现 DeepSeek 隐藏 Bug:加空格模型翻车 "省钱杀手锏"成致命盲区
重磅·产学研
🇨🇳 中国动向 学术成果 前沿产业 LLM 工程 红队测试 字节 × DeepSeek

🎓 学术字节 Seed 团队在测试 DeepSeek 成本优化策略时,发现一个隐藏的工程 bug:在特定 prompt 位置加入一个空格字符,即可触发 DeepSeek 模型的解码异常,使原本应连续输出的 token 被截断或错位;该 bug 与 DeepSeek 引以为傲的"峰谷定价 + 极低 token 消耗"路由策略存在耦合,空间字符干扰了 KV Cache 复用逻辑,导致推理结果"翻车"——这是国内大模型公司首次系统性披露同行 LLM 的可被低成本复现的工程缺陷。

🏢 产业对 DeepSeek 而言,该 bug 一旦被攻击者大规模利用,可能导致 token 计费异常、用户复现率下降,影响其"低价 + 高吞吐"商业化护城河;对字节而言,该发现意味着在 V4.1 DSec (5000 沙盒/秒 + 38 万并发) 的工程能力下,可以在"如何用极小扰动让同类模型出错"上形成新的护城河;后续可能引发一轮"红队测试 + 鲁棒性修复"军备竞赛,所有 LLM 厂商需要重新审视自己的 token 路由 + KV Cache 复用代码。

关键数据:1 个空格字符触发解码异常;DeepSeek 峰谷定价 + 极低 token 路由策略存在耦合;字节 Seed 内部复现 + 已告知 DeepSeek;雷峰网/量子位 10-10 同步报道;后续将推动 LLM 厂商红队测试军备竞赛。

Galahad 推出 5000 万 token 长期记忆服务 解决 Agent 跨会话上下文断裂痛点
观察
🌍 全球信号 产品落地 前沿产业 长期记忆 Agent 基础设施 Corbenic AI
