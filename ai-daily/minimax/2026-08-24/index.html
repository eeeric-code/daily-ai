重磅·开源
开源生态 蚂蚁百灵 Ling-3.0 checkpoint 开放 🇨🇳 中国动向

🎓 学术蚂蚁百灵 8-22 宣布将 Ling-3.0-tiny-base 与 Ling-3.0-flash-base 正式开源,除最终 Base checkpoint 外,同步开放两个模型的预训练和中期训练的权重 checkpoint,共计 6 个 checkpoints。这一做法打破国内外主流大模型"只开源最终权重"的惯例,研究者可在 4 个时间节点上对训练过程做"中段回放",用于训练动力学分析、Scaling 行为复现、安全对齐残差评估,大幅提升学术研究的可重复性。

🏢 产业Ling 系列是蚂蚁"通义-百灵"双品牌战略中面向 B 端应用与海外开源社区的主力模型,本次基础权重批量下放使其能直接进入 Hugging Face / ModelScope 的训练工作流,与 Qwen / GLM / Kimi 共同构成中国开源模型在 Hugging Face 趋势榜上的"四强格局",也意味着蚂蚁在 MaaS 层面向开发者的吸引力正与日俱增。

关键数据:6 个 checkpoint(tiny + flash × Base + 预训练 + 中期 + 最终);Ling-3.0 系列是蚂蚁灵波从纯文本向多模态延伸的关键版本;在 Hugging Face 趋势榜上,Ling-3.0 与 Qwen3.8-27B / Kimi K3 形成同期开源矩阵;8-22 同步释放 Files API 与 DeepSeek Harness 0.1.1 类似工具链,显式鼓励"基于中间状态做后训练"的研究路径。

法国 Pasqal《Nature》发文:AI 智能体自主生成并运行量子计算代码,量子氛围编程首次实现
顶刊级
量子计算 氛围编程 中性原子阵列 Pasqal 🌍 全球信号

🎓 学术法国量子计算初创企业 Pasqal 在《Nature》发表论文,展示其 AI 智能体可依据英文自然语言指令自动生成量子计算代码,并在真实量子计算机(中性原子阵列)上端到端运行,完成"量子模拟"任务的代码—执行—验证闭环。研究人员对智能体进行 3 项测试,每项选取一篇描述物理现象的论文,要求智能体复现并验证。Pasqal CTO 伊克·亨里耶指出,通常需要同时具备材料物理与量子计算知识的跨学科团队才能完成,AI 智能体显著压缩了人力成本。

🏢 产业"量子氛围编程"是 LLM 编程能力从经典软件(SWE-Bench)向量子计算垂直领域延伸的标志事件,意味着 QuEra / IonQ / IBM Quantum 等头部量子云服务可借助 LLM 实现"低门槛用户接入",加速材料/催化/磁性等领域的客户验证;但论文也强调在实验物理准确性的关键环节,人类研究人员仍不可或缺,AI 不会完全替代专家。

关键数据:3 项论文级物理验证任务全部由 AI 智能体完成;依托中性原子阵列硬件;在 1 项任务中,智能体需要人类提供较多指导,才能得到符合物理规律的实现方案;同期纽约大学阿布扎比分校基于 LLaMA 的量子代码生成工具,已将 4 天工作压缩到 1 天。
