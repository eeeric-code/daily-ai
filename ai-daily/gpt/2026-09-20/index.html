基准发布
物理推理多模态视频理解评测
🎓 学术MiniMax-H3 汇集 517 个需要视觉、视频或音频证据的物理世界问题，用可验证答案评估模型能否从动态观测推断因果与状态。论文报告总体正确率 41.97%，视频子集为 56.00%，需要音频消歧的子集只有 27.40%，显示跨模态证据融合仍是明显瓶颈。

关键数据：517 个实例、总体 41.97%、视频 56.00%、音频消歧 27.40%；多模态推理尚未形成稳定物理表征。

覆盖: 主动视觉 · GUI 技能 · 观测监督 · 多智能体协作
VABench 揭示主动视觉的收益与缺口：最佳系统宏成功率仅 53.93%
基准发布
主动视觉机器人基准视角选择泛化
🎓 学术VABench 用 14 个任务家族和 7 个留出变体评估机器人是否会主动移动相机以解决遮挡与歧义。最佳方法宏成功率为 53.93±3.17%，在部分设置中主动选视角把成功率从 27.86% 提高到 57.50%，但严格长程完成仍不稳定。
🏢 产业基准说明相机动作本身应成为策略输出，而不是固定前处理；同时翻倍提升仍可能停留在半数成功。机器人团队应分开统计看见目标、选择视角、操作执行和恢复失败，并在真实相机时延与碰撞约束下复测。

关键数据：14 个任务家族、7 个留出变体、最佳宏成功率 53.93±3.17%；主动视角可将一项设置从 27.86% 推到 57.50%。

自演化搜索索引让 Agent 改写检索结构：索引优化器与查询模拟器形成闭环
检索系统
搜索 Agent索引优化RAG自我演化
🎓 学术Self-Evolving Search Index 不把索引视为固定基础设施，而是让优化器诊断召回失败、重写键与分区，再由查询模拟器生成压力测试，循环改进面向 Agent 的检索结构。论文关注的不只是排序器，而是查询、索引和评测共同演化。
🏢 产业知识库产品可针对真实任务自动调整索引，但自优化也可能过拟合模拟查询、破坏可解释路径或放大热门内容。落地应保留版本、回放集和回滚点，按事实命中、权限隔离、索引成本与冷门查询表现联合验收。

关键判断：检索优化从调排序器扩展到可迭代的索引结构与查询模拟闭环；生产价值取决于稳定回归和可回滚性；判断成色仍要看公开工件、独立评测和可审计交付。

EOS 语义错配会让推理模型停不下来：正确答案后仍可生成数千冗余 Token
机制研究
EOS推理模型终止控制强化学习

关键数据：示例轨迹在 1,094 Token 已正确，却延伸至 7,098 Token；结束符训练需要对齐“任务已完成”的语义。

只报 sample count 会误判推理成本：串行 8 次采样能耗可达批处理的 4.86 倍
系统评测
推理能耗批处理尾延迟系统基准
🎓 学术研究指出相同 N 次采样在串行、批处理与并发实现下有完全不同的能耗和延迟。N=8 时，串行 8×1 相比一次批处理 1×8 使用 4.64—4.86 倍能量，P95 延迟达到 5.77—6.12 倍，说明 sample count 不是充分成本指标。
🏢 产业模型评测和采购应同时披露批大小、并发、硬件、功耗采样与尾延迟，否则 best-of-N 容易隐藏系统代价。平台团队还应测服务负载下的排队和利用率，避免把实验室批处理优势直接外推到交互业务。

关键数据：N=8 串行方案能耗为批处理的 4.64—4.86×，P95 延迟为 5.77—6.12×；成本报告必须描述执行形态。
