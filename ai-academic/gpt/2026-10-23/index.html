Orbitol：在 Wyckoff 轨道上生成保留指定对称性的晶体
预印本
学术成果 晶体生成 对称性约束 首次提交 10-22 01:33 UTC+8
研究贡献Orbitol 将 Crystalite 扩散模型的原子 token 改成 Wyckoff 轨道 token，给定空间群和占据位置后，联合生成元素、自由坐标及兼容晶格。有效解码结构天然满足指定对称操作，并用 SPARC 同时衡量弛豫后的对称性保留与训练分布覆盖，适合定向探索压电晶体类别。
证据与局限作者在 MP-20 上每模型评估 2500 次尝试，稳定或亚稳、独特、新颖且保留指定空间群的比例为 13.8%，SGFM 为 10.8%。压电候选的 89% DFT 通过率仅针对内部筛选后子集，不代表全部生成物，更非合成成功率；训练种子有限，未找到可核验的专属代码仓库。

研究重点是把材料对称性写进生成表示，而非生成后再筛。单卡大批量采样约每秒 920 个结构的计时排除了加载、编译与弛豫成本；将其换算为完整材料发现加速仍需补充实验。

BatchBench：让细胞图像模型在未知实验批次上接受检验
预印本
学术成果 细胞成像 分布偏移 首次提交 10-22 01:50 UTC+8
研究贡献BatchBench 基于 JUMP Cell Painting 构建覆盖 2000 种化合物的分类评测，用来源级拆分隔离实验条件变化。九个公开来源用于训练和验证，另四个来源保留为私有测试；容器接口支持测试时适应，提交需固定 Git 提交，使方法比较与运行环境可追踪。
证据与局限实验比较基于 ResNet18 的标准训练、域不变学习、测试时适应和元学习方法。作者发现适应可缩小域差距，却未解决少样本化合物接近随机水平的问题。代码、训练及提交示例可访问；私有测试标签不开放，且该结论来自细胞染色图像，不能直接外推临床影像。

这项工作的价值是把跨实验室泛化变成可重复的评测问题。低分辨率开发集便于试验，但正式排名在完整分辨率私有集上计算；当前榜单界面未在静态抓取中完整展开，因此不引用即时排名。

LIBERO-10 闭环评测：通用模型的推理仍难稳定转为操作
预印本
学术成果 机器人仿真 闭环控制 首次提交 10-22 01:11 UTC+8
研究贡献研究让通用模型读取相机图像与机器人状态，通过末端位姿和夹爪工具直接控制 LIBERO-10 仿真机械臂，不做任务专用微调。统一框架评测六个模型、三档推理强度，共 18 个配置与 1800 回合，把视觉定位、规划和动作执行放在同一闭环中观察。
证据与局限每配置使用相同任务与初态的 100 回合；最高成功率为 GPT-6 Astra 高推理档的 44%，Gemini-4 Argon 为 43%。一百分点差异不能据此认定显著领先。预算、调用次数及输出限制触发也记为失败；这是仿真与特定工具接口下的结果，非真机能力排名，评测代码已开放。

更高推理强度通常带来收益，但成本和任务差异明显，精细空间排列仍困难。作者提供框架和结果，后续复现需固定模型版本、推理档位及预算，避免把 API 变化误当控制方法进步。

ToM2Vec：用连续潜在 token 学习伙伴的信念与行动
预印本
学术成果 多智能体 潜在推理 首次提交 10-22 00:05 UTC+8
研究贡献ToM2Vec 用固定数量的连续 token 表达伙伴的可能状态，训练时与伙伴真实推理的隐藏表示对齐，测试时由智能体自行生成这些表示并据此行动。方法不直接优化任务奖励，而是检验潜在伙伴建模能否改善合作、竞争及混合动机互动。
证据与局限在 Qwen3-8B 上，作者报告 Overcooked 平均提高 12 分，100 次谈判的达成率从 62% 升至 71%，并比较文字化 ToM 等基线。训练需伙伴推理及共享表示空间，实验仅涵盖英语游戏；跨模型伙伴测试不等于真实人类协作验证。训练和评测代码可访问。

这项工作把伙伴建模从显式文字总结推进到潜在表示，并用信念、愿望、下一步行动问答辅助检验。收益证据集中在受控环境，尚不能据此宣称模型已具备人类意义上的心智理解。

🧠 主题 3 · 基础模型与多模态

覆盖：生成机制 · 扩散语言模型 · 循环深度
LAW：全程传播期望嵌入，最后一步才解码语言 token
预印本
学术成果 生成建模 自条件化 首次提交 10-22 01:25 UTC+8
研究贡献LAW 探索纯自条件化生成：从随机 token 起步，此后只传播去噪预测对应的期望嵌入，直到最后一步才离散解码。方法结合温度正则与多次前向训练，在数独、迷宫、数学推理及文本生成上比较扩散、流模型和自回归模型，检验中间离散采样是否必要。
证据与局限作者在 TinyGSM 训练、温度 1 与 1024 次网络求值条件下，报告 GSM8K 42.2%，对应 LDDM-U 为 34.5%；Duo 微调另有 17.2% 至 48.1% 的结果。两组设置不可混用，较多采样步也有成本。代码已公开，大规模有效性未证实，文本生成还存在熵范围收窄问题。

论文提供了连续状态保留预测不确定性的可检验方案。比较时须同时看训练 FLOPs、采样求值次数和输出多样性，单看困惑度或一道推理题的准确率不足以判断整体生成质量。

Looped UDLM：重复早期网络层降低扩散语言模型训练开销
预印本
学术成果 扩散语言模型 循环深度 首次提交 10-22 01:24 UTC+8
研究贡献Looped UDLM 保持均匀扩散训练目标与采样器不变，在每次去噪中重复执行早期 Transformer 层，通过共享权重增加有效计算深度。训练随机采样循环次数，推理可固定深度或按状态收敛提前退出，从而研究参数规模不变时计算分配的作用。
证据与局限实验使用 170M 参数、1024 长度模型，在 OpenWebText 和 FineWeb-Edu 上达到非循环基线验证 NLL 所需 FLOPs 最多减少约 2.8 倍和 3.3 倍。结果来自小规模模型；只训练循环而在推理时仅跑一遍会损失域外效果。代码和检查点页面可访问，FLOPs 改善不等于等比例墙钟加速。

该研究与 LAW 分别改变网络执行深度和生成状态，两者是独立机制。论文强调推理循环本身不可省略，复现应同时报告训练计算量、实际循环次数及延迟，而不只统计参数数量。

LongZero：先生成证据骨架，再扩写长上下文训练任务
预印本
学术成果 长上下文 自生成数据 首次提交 10-22 01:59 UTC+8
研究贡献LongZero 让模型先写出问题、答案及支持事实的紧凑结构，再扩写成长篇多文档上下文，混合自生成的多轮检索任务进行 GRPO。训练保留模型回答不稳定的题目，使自造任务既可核验又有学习空间，减少长上下文后训练对外部语料与更强教师的依赖。
证据与局限作者在 Qwen3-4B-Thinking 与 Qwen3-8B、五组长上下文基准上比较两类外部语料合成基线；每模型训练含 2304 道推理题及 1152 个检索会话。零外部数据指本轮后训练，不抹去基座预训练知识或人工任务设计；合成和筛选仍需计算。代码、数据入口及逐题结果已提供。

先固定答案和证据，再扩写文本，有助于降低长文造题时的自相矛盾。结果支持自生成数据可迁移到所测任务，但仅有两种较小基座，尚不足以证明模型能无限自我提升或摆脱外部验证。

EPIC：用前缀概率比约束离策略语言模型强化学习
预印本
学术成果 强化学习 MoE训练 首次提交 10-22 00:37 UTC+8
研究贡献EPIC 将自回归生成中的策略漂移放到整个已生成前缀上处理，用累计重要性比和精确反向 KL 坐标构造裁剪目标。方法在 token 级高效计算前缀信赖域，试图改善长响应、离策略 MoE 训练稳定性，并减少记录和回放专家路由所需的系统负担。
证据与局限在 Qwen3-30B-A3B-Base、DAPO-Math-17K 及四项数学评测上，三次独立训练的平均准确率为 39.34%，GSPO 为 32.84%。内存下降针对驱动侧进程，不能写成 GPU 总显存下降。代码已公开，但实验限于一个 MoE 基座和数学任务，理论推导也不保证实际裁剪训练全程单调提升。

这项工作提供了分析策略更新粒度的具体对象：已生成前缀的分布变化。比较路由回放替代方案时，除准确率外还应区分 CPU 进程内存、GPU 显存与吞吐，避免混淆系统收益口径。

🔍 主题 5 · 评测、安全与可解释性

覆盖：模型组合 · 能力诊断 · 行为实验
LMCircuit：自适应组合分类模型，在成本约束下决定何时停止
预印本
学术成果 模型组合 可靠性评测 首次提交 10-22 01:27 UTC+8
研究贡献Circuits of LLM Classifiers 把语言模型分类器视为带噪测量工具，先学习标签与各模型回答的联合分布，再用动态规划选择下一次查询或停止。相比固定路由和级联，查询路径可随已经观察到的回答变化，目标是在给定平均调用成本下提高分类准确率。
证据与局限作者在七项分类任务上报告优于路由、级联基线的成本—准确率前沿，代码提供数据接口与复现流程。精确最优性依赖已知分布，实际由标注数据估计；动态规划复杂度随模型池指数增长，部分基准调用成本为估算。任务包含健康等领域，但不构成临床可靠性认证。

核心启示是模型互补性可能比单个模型的榜单位置更重要。应用前需重新校准联合误差、真实调用价格与任务分布；已有标注上的最佳停止策略未必能直接迁移到变化中的线上数据。

TIDE：从作答行为诱导诊断树，揭开平均分掩盖的弱项
预印本
学术成果 细粒度评测 能力诊断 首次提交 10-22 00:27 UTC+8
研究贡献TIDE 从样本和模型评分矩阵递归构建能力树：由语言模型提出划分规则并分类样本，再按行为信息增益选择节点。它不只输出总分，而是定位可解释的能力子集，比较弱项在留出样本上的稳定性，以及不同模型和版本之间的局部差异。
证据与局限在 MMLU-Pro、BBH、DROP、BBQ 上各抽取 3000 题，一半建树、一半测试，并与 TextDiff、EvalTree 等比较。作者展示总分接近却局部差距显著的情况，但节点分数受样本量和裁判影响。实验限于静态英语单轮评测，未验证开放生成或智能体任务；未找到专属代码链接。

树形诊断可辅助决定下一步补哪些训练数据，但它是行为分组，不等同于识别模型内部的因果机制。复核弱项时应查看节点样本量、留出一致性和裁判开销，避免被极小子集的百分比误导。

FrontierCS 2：删去论文代码贡献，让智能体在原仓库补回并超越
预印本
学术成果 科研智能体基准 研究复现 首次提交 10-22 00:04 UTC+8
研究贡献FrontierCS 2 将论文作者发布的代码贡献移除，保留依赖和研究环境，让智能体提交补丁并接收开发集反馈，最后在隐藏工作负载上对照作者实现。48 道开放任务覆盖 13 个计算机领域，通过要求是每个指标和工作负载都胜过参考，而非仅综合分更高。
证据与局限作者评测 12 个模型与各自工具框架的组合，每题每组合运行一次；最高通过率 58%，有 16 题无一次通过。成绩因此同时受框架、预算和随机性影响，不能直接解释为科研能力占比。仓库已公开 48 道任务及固定镜像说明，另有百余道私有任务，完整复现需要额外计算资源。

把任务放回原研究仓库，使测试更接近修改、测量、迭代的真实科研过程。单次运行与既有论文代码也带来方差和潜在记忆因素，后续应关注多次运行、污染审计及未见任务的表现。

Environment Duels：让模型同时出题、解题并提供有效提示
预印本
学术成果 动态基准 模型共演化 首次提交 10-22 01:55 UTC+8
研究贡献Environment Duels 让模型编写交互环境与特权提示，再由同组模型分别在有提示、无提示条件下求解，分开衡量解题率、环境难度和提示增益。九个模型的交叉互动显示，擅长解题不必然擅长设计挑战，为持续更新智能体评测提供了一种受控实验框架。
证据与局限公开仓库含 90 个环境、轨迹及分析脚本；论文另以四个作者各 200 个环境训练 Qwen3.8-27B，观察提示增益与留出基准改善的关系。环境有效性依赖程序检查、模型审阅和人工审计；这种相关性不证明普遍因果，已公开的评测材料也不等于完整强化学习实验全部可复现。

这项研究把出题能力与答题能力拆开观察，避免用一个榜单分数代替二者。论文中的共演化是对受控模型互动的描述，尚不能据此推断开放网络上长期自我改进的速度或稳定性。
