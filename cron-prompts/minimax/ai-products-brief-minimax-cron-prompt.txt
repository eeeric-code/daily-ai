## Step 2.6: URL 真实 fetch 验证(2026-07-11 升级)

> **用户硬性要求**:7-11 简报里 32 条 deep_link_only(首页/目录页)+ 5 条 fail,用户体验差。cron 必须严格验证每条 URL,失败则重新搜索,不接受降级到首页。

对每个候选的所有 URL 做 webfetch,执行以下 5 步验证:

```python
def validate_url_strict(url, card_keywords):
    """返回 (status, level, error)"""
    # Step 1: fetch
    try:
        content = webfetch(url, timeout=15)
    except Exception as e:
        return ('fail', 'fetch_error', str(e)[:80])

    if not content or len(content) < 200:
        return ('fail', 'empty_body', 'body too short')

    # Step 2: fake-200 检测
    fake_200_signals = ['宝贝回家', 'babyhome', '您访问的页面不存在', 'page not found',
                        '404 Not Found', 'Access Denied', '请输入验证码']
    if any(s in content for s in fake_200_signals):
        return ('fail', 'fake_200', 'page content is 404/wall')

    # Step 3: 禁止首页/目录页模式
    import re
    homepage_patterns = [
        r'^https?://[^/]+/?$',                          # https://example.com/
        r'^https?://[^/]+/(index\.html)?$',             # https://example.com/index.html
        r'^https?://[^/]+/blog/?$',                     # /blog 索引
        r'^https?://[^/]+/news/?$',                     # /news 索引
        r'^https?://[^/]+/blog/index\.html?$',
        r'^https?://[^/]+/products?/?$',                # 产品列表
        r'^https?://[^/]+/articles?/?$',                # 文章列表
    ]
    for pat in homepage_patterns:
        if re.match(pat, url):
            return ('fail', 'homepage', f'url 命中禁止首页模式 {pat}')

    # Step 4: 禁止企鹅号 / 微信公众号
    if 'so.html5.qq.com' in url or 'mp.weixin.qq.com' in url or 'new.qq.com/rain' in url:
        return ('fail', 'wechat_closed', '企鹅号/微信封闭生态,公网不可达')

    # Step 5: 主题词匹配(至少 1 个 card 关键词出现在 body)
    body_lower = content.lower()
    matched = sum(1 for kw in card_keywords if kw.lower() in body_lower)
    if matched < 1:
        return ('fail', 'topic_mismatch', f'no card keyword in body ({matched}/3+)')

    return ('pass', 'pass', '')
```

**标记规则**(沿用通用版):
- `[OK]`: Step 1-5 全过
- `[DEAD]`: fetch_error / http 4xx 5xx
- `[FAKE-200]`: 内容是 404 / babyhome / 验证页
- `[HOMEPAGE]`: URL 命中禁止模式
- `[WECHAT-CLOSED]`: 企鹅号/微信
- `[TOPIC-MISMATCH]`: 主题不匹配
- `[NO-REF]`: 任何 fail

**重试策略**:每条候选的所有 URL 跑 validate_url_strict。
- ≥ 1 个 URL 通过 → 保留,移除 fail 的 URL
- 全部 URL fail → web_search 重找真源(限 3 次,不限 site:)
- 仍找不到 → 标记 `[NO-REF]`,降级为"二手解析"卡(不写 reference),或删除该卡

- ❌ "假设的 URL"进入 candidates(LLM hallucination)

```python
    (r'href="https?://[^/]+/blog/?"', 'blog 索引页'),
    (r'href="https?://[^/]+/news/?"', 'news 索引页'),
    (r'href="https?://[^/]+/articles?/?"', 'articles 索引页'),
    (r'href="https?://[^/]+/products?/?"', 'products 索引页'),
    (r'href="[^"]*so\.html5\.qq\.com/', '企鹅号转载(封闭生态)'),
    (r'href="[^"]*mp\.weixin\.qq\.com/s/', '微信公众号原文(封闭生态)'),
    (r'href="https?://new\.qq\.com/rain/', '腾讯 news.qq.com(fake-200 重灾区)'),
]

# 一手源数量统计
primary_count = 0
for h in re.findall(r'href="(https?://[^"]+)"', html):
    if any(domain in h for domain in ['.gov.cn', '.gov/', 'sec.gov', 'hkex.com.hk', 'github.com', 'arxiv.org', 'nature.com', 'science.org']):
        primary_count += 1

# 自检
fail_count = 0
for pat, desc in banned_patterns:
    matches = re.findall(pat, html)
    if matches:
        print(f"⚠ 自检 FAIL [{desc}]: {len(matches)} 处")
        for m in matches[:3]:
            print(f"    {m}")
        fail_count += len(matches)

# 一手源数量
if primary_count < 12:
    print(f"⚠ 自检 FAIL [一手源不足]: {primary_count} < 12")
    fail_count += (12 - primary_count)

if fail_count > 0:
    print(f"\n=== 自检 FAIL count: {fail_count} ===")
    print("**禁止 commit + push**。必须 web_search 找真源替换或删除该卡。")
    # 触发 autofix: web_search 找真源
    # 限 3 次,失败标记 partial_skip
    raise Exception("Step 3.5 自检 FAIL,不能 commit")
else:
    print("✓ Step 3.5 自检 PASS - 24 张卡无首页/企鹅号/微信/缺源")
```

**自检 FAIL 时的处理**:
1. 列出所有 fail URL
2. 对每条 fail URL 重新 web_search(限 3 次,不限 site:)
3. 找到真源 → patch HTML
4. 找不到 → 标记 partial_skip,或删除该 reference,或降级该卡
5. 全部处理完后重跑自检,直到 PASS 才能进 Step 4

**绝对禁止**:自检 FAIL 时仍然 git commit + push。

### 4.4b 校验部署版首页卡片(必做,不能只看命令输出)

